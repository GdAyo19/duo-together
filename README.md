# Tandem

A small, static couples-language-learning prototype for Okomi and Ifemi. It includes a shared dashboard, language selection, short phrase games, pronunciation playback, and demo progress.

## Run locally

Open `index.html` in a browser, or serve this directory with:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

This prototype stores no accounts or shared progress and does not connect to Duolingo. Progress updates are local demo interactions.
